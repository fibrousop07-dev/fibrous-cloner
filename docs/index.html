From a URL to a local copy.

Install Node.js 18 or newer, then run these commands. No npm dependency installation is needed.

Open http://localhost:4200, add a website URL to the queue, and choose Start localhost on the saved copy.

Only copy sites you own or have permission to copy.

git clone https://github.com/fibrousop07-dev/fibrous-cloner.git
cd fibrous-cloner
npm start

Prefer a terminal?

These commands use an illustrative domain. Substitute a website you own or have permission to copy.

# Download, preview and choose whether to keep the copy.
node sitecloner.mjs https://example.com

# Keep the copy without opening a browser automatically.
node sitecloner.mjs https://example.com --no-open --answer y

# Preview an existing copy on a chosen port.
node sitecloner.mjs serve ./clones/example.com --port 4300

See the README for command options and configuration.

Know what a website copy includes.

This tool copies browser-accessible frontend files and public responses. It cannot download the original server source, private database, passwords or authenticated data. Bot protection and private APIs can prevent a complete copy.

A localhost preview may still request uncaptured resources from the original website. Test a copy before relying on it as an offline archive. The crawler is not a full browser-rendering engine, and a copied application is not a replacement production deployment.

Website cloning, explained.

What is fibrous-cloner?

fibrous-cloner is a local website cloner and downloader with a control panel and Node.js CLI. It saves accessible frontend files and public API responses for localhost previews.

How do I clone a website to localhost?

Install Node.js 18 or newer, clone this repository, and run npm start. Add a permitted website URL to the queue, then choose Start localhost. From a terminal, run node sitecloner.mjs followed by the URL.

Is it free and open source?

Yes. The desktop tool and CLI are MIT licensed and have zero npm runtime dependencies. Running the source does not require a hosted account.

Does it download the backend or database?

No. Server source, private databases and authenticated data cannot be downloaded. Public API snapshots contain saved responses available to a logged-out visitor.

Can it copy React or Vue websites?

Accessible JavaScript bundles and assets can be saved, and detected client-side routes are supported. Private APIs, browser-rendered content and live services can leave copies incomplete.

Can it bypass logins or bot protection?

No. If an automated download is refused, a permitted page saved in your browser can be imported. This does not guarantee a complete working application.

Will a downloaded website work offline?

Captured files and public API responses can be served locally. Uncaptured resources may still request the original website or fail. Test the copy before relying on it as an offline archive.

When is this site cloner a useful choice?

Use it for a managed local website library, CLI downloads, localhost previews and public API snapshots of sites you own or have permission to copy. It is not a backend migration or production deployment tool.
